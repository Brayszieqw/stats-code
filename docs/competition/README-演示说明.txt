Stats Code 竞赛演示包
====================

Stats Code 是面向医院科研、公卫与医学院校的本地可审计观察性研究智能体。
统计数值由本机确定性引擎计算，不由大语言模型生成；未配置 LLM 时仍可运行完整研究流程。

三步启动
--------
1. 解压整个 StatsCode-Demo-Pack 压缩包。
2. 双击 stats-code.exe，等待浏览器自动打开；如浏览器未自动打开，请访问
   http://127.0.0.1:8080（若端口被占用，程序会在 8080—8200 中选择空闲端口）。
3. 选择“暂不配置，进入专业模式”，打开“协议”→“加载演示协议”→“审批协议”；
   上传 data\demo_cohort.csv，选择“基线特征表”，分组变量选 disease，连续变量选 age、bmi，
   分类变量选 sex、smoke；审阅数据质量卡后点击“批准方案并运行”。

界面说明
--------
- 主画布：保留任务对话与结果摘要，降低信息噪声。
- 研究状态机：协议 → 质控 → 方案审批 → 确定性执行 → 诊断与导出。
- 检查器：用右上角“检查器”按钮按需展开报告、图表、数据和等价代码。
- 分析方案审批：运行前固定显示方法、变量、样本量、缺失率及统计风险提醒。
- 可信标识：本机确定性引擎 · 数值非 LLM 生成 · 可审计。

安装（可选）
------------
在 PowerShell 中运行 install.ps1，可安装到当前用户目录并创建桌面快捷方式；
直接运行 stats-code.exe 无需安装，也不依赖本机 Node.js、R、Python、SAS 或 SPSS。

验证
----
SHA256SUMS.txt 校验静态交付文件。冷启动验证记录.md 记录打包时连续三轮
“启动 → 健康检查 → 建会话 → 上传 CSV → 运行 Table One → 退出”的真实结果。
如需在当前机器重新验证，请在 PowerShell 中运行：

  powershell -ExecutionPolicy Bypass -File .\verify-demo-pack.ps1
