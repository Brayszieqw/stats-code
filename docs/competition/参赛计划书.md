## 1. 一句话与定位

**Stats Code 把医院科研 / 公卫 / 医学院校的观察性研究问题转成可审批的研究协议与分析方案，由本机确定性引擎执行，并交付可审计、可复现的研究包。**

LLM 只负责意图引导与文字解释，不生成或改写统计数值；方法、数据指纹、协议审批、运行结果与等价代码均保留为复核证据。

| 项 | 内容 |
|----|------|
| 行业标签 | **AI + 医疗** |
| 用户 | 医院临床研究者、公卫研究者、医学院校科研团队 |
| 差异点 | 本地隐私 · 数值非 LLM 生成 · 可审计 / 可核对等价代码 |
| 现实目标 | 海选进百强 → 冲 35 强；不包装成院级全平台 |

**固定责任边界**：本产品仅提供科研设计与统计分析辅助，不独立作出诊断、治疗或个体决策；所有研究结论须由具备资质的研究者审核确认。

---

## 2. 要解决的问题

1. 通用聊天模型「随口出 p 值」不可信，且无法审计。  
2. 专业软件（SPSS/SAS/R）学习曲线陡，教学场景难快速闭环。  
3. 医疗与队列数据不宜默认上云；需要 **本机可运行** 的智能体形态。  
4. 现有在线计算器缺少项目上下文、方法白名单与可复现打包。

---

## 3. 产品方案（智能体如何工作）

### 3.1 角色拆分（核心原则）

| 角色 | 做什么 | 不做什么 |
|------|--------|----------|
| LLM | 理解意图、解释报告、引导配置 | **不生成 / 不改写统计数值** |
| 确定性引擎 | Table One、回归、生存等 17 类进程内算法 | 不 spawn 外部 R/SAS/SPSS 偷算 |
| 人 | 审批研究协议与分析方案、审核结论、承担最终研究责任 | 不把软件输出直接当作诊疗决定 |

### 3.2 主路径（Demo 与日常）

1. 启动本机应用（桌面壳或 SEA exe）→ 仅监听 `127.0.0.1`。  
2. 可「暂不配置 LLM」进入专业模式；统计路径不依赖外网。  
3. 建立并审批 15 字段研究协议卡（问题、设计、人群、时间零点、estimand、缺失与敏感性策略等）。
4. 上传 / 一键加载演示队列 `demo_cohort.csv`，进入不可跳过的数据质量卡。
5. 配置方法与变量 → **分析方案审批**（方法、n、缺失率、小样本/因果/配对等风险）。
6. 本机引擎运行 → 结果 / 诊断 → 等价代码与覆盖等级 → 审计快照。
7. 「关于与能力边界」明确 **支持 / 不支持**（不伪装 PSM、TMLE、竞争风险等）。

### 3.3 交付形态

| 形态 | 说明 |
|------|------|
| **桌面壳（推荐 GUI）** | Electron 应用内窗口，后端 `--no-browser`，不依赖系统浏览器 |
| **单文件 SEA** | `stats-code.exe` 内嵌前端；亦可浏览器打开（兼容） |
| **Demo-Pack** | exe + 演示数据 + 三步说明 + 剧本 + 冷启动验证记录 |

## 4. 技术架构（摘要）

详见同目录 `技术架构说明.md`。分层如下：

1. **表现层**：React + TypeScript；对话主画布 + 按需「检查器」。  
2. **本机 API**：Fastify loopback；会话 / 数据集 / run / SSE。  
3. **统计引擎**：TypeScript 进程内算法（ADR-0003）；parity 与属性测试护栏。  
4. **可信凭证**：研究协议审批、方案审批时间、数据集 SHA-256、algorithm_id、run_id、覆盖等级与能力边界。
5. **可选 LLM**：API Key 本地配置；失败时点选 / Pro 路径仍可跑通。

---

## 5. 创新点与边界诚实

### 5.1 创新点（评委 3 分钟能听懂）

1. **可信拆分**：智能体 ≠ 模型心算 p 值。  
2. **本地优先**：医疗隐私叙事与落地一致。  
3. **可核对**：等价 R/Python/SAS/SPSS 代码侧栏 + 运行元数据。  
4. **研究状态机**：协议 → 质控 → 方案审批 → 确定性执行 → 诊断与导出。
5. **方法守卫最小集**：小 n、高缺失、因果措辞、配对误用独立样本检验等前置提示。

### 5.2 明确不做（本阶段）

PSM / TMLE / 竞争风险 / 时空与传染病全平台 / CDISC·TFL 全流程 / 公网多租户。  
原因：无导师金样时「多而错」比「少而准」更危险。

## 6. 演示与验证计划

### 6.1 海选视频（≤5 分钟）

按 `演示剧本.txt` + `录屏检查清单.md` 录制：

| 时间 | 画面 | 字幕/口播 |
|------|------|-----------|
| 0:00–0:25 | 启动桌面应用 / exe | 本地一键，数据不出机 |

| 2:50–3:25 | 报告 / 图 / 等价代码 / 覆盖等级 | 可核对且不混淆验证水位 |
| 3:25–3:50 | 审计快照 + 能力边界 | 可复现，支持与不支持诚实列出 |
