# 海选 Demo 录屏检查清单（≤5 分钟）

> 目标产物：`demo.mp4`（建议 1080p、3–4 分钟、≤5 分钟）  
> 剧本：`演示剧本.txt`  
> **必须用 prod 路径**（桌面壳或 `stats-code.exe`），不要用 Vite 开发窗露馅。

---

## A. 录前环境（10 分钟）

| # | 检查项 | 完成 |
|---|--------|:----:|

| 2 | 推荐：用 `启动Stats桌面.bat` / 桌面壳，界面在**应用内** | ☐ |
| 3 | 备选：`stats-code.exe` + 系统浏览器（需在口播说明本地） | ☐ |
| 4 | 分辨率 1920×1080；缩放 100% 或 125% 固定 | ☐ |
| 5 | 关闭微信/QQ/邮件弹窗；勿扰模式 | ☐ |
| 6 | 桌面干净；任务栏少图标 | ☐ |
| 7 | 演示数据路径固定：`data\demo_cohort.csv` 或一键加载 | ☐ |
| 8 | **故意不填 LLM Key**，走「暂不配置，进入专业模式」（突出离线统计） | ☐ |

## C. 镜头顺序（对照剧本）

| 镜号 | 时长 | 操作 | 必须入镜的字样 |
|------|------|------|----------------|
| 1 | 25s | 启动应用 | 本机 / 127.0.0.1 或桌面窗口标题 |
| 2 | 25s | 暂不配置 LLM | 「暂不配置，进入专业模式」 |
| 3 | 35s | 加载并审批演示协议 | 时间零点 / estimand / 审批协议 |
| 4 | 25s | 上传或一键演示数据 | `demo_cohort` |
| 5 | 25s | 配置 Table One | disease / age,bmi / sex,smoke |
| 6 | 30s | 数据质量卡与方案审批 | 方法、n、缺失、风险、「批准方案并运行」 |
| 7 | 35s | 结果摘要 | 「本机确定性引擎 · 数值非 LLM 生成」 |
| 8 | 30s | 检查器：报告 / 图 / 代码 | 覆盖等级与等价代码 |
| 9 | 25s | 审计快照与能力边界 | 不支持 PSM/TMLE… |
| 10 | 10s | 收束四句 | 协议先行 · 本地执行 · 人审 · 可审计 |

**总时长目标：3:40–4:20**（留剪辑余量，不超过 5:00）。

---

## D. 字幕建议（5 句）

1. 本地可审计的观察性研究智能体，数据不出本机
2. 无 API Key 也能跑完整统计  
3. 协议与分析方案先审批，再执行统计
4. 数值由确定性引擎计算，不是模型猜的  
5. 等价代码与能力边界可核对、不夸大  

---

## E. 翻车预案

| 现象 | 处理 |
|------|------|
| 端口被占 | 关掉旧 `stats-code` / Electron 再开 |
| 一键演示 404 | 确认 SEA 已嵌入 `demo_cohort.csv`；或改用文件上传 |
| 表出得慢 | 用自带 240 行 demo，勿换大 CSV |
| 误开 Vite | 重录；标题栏不要出现 localhost:5173 开发字样（可用，但不够「成品」） |
