# Stats Code 技术架构说明

Stats Code 采用“界面交互、统计执行、可信凭证”分层架构：

1. React + TypeScript 前端提供 Codex 风格单任务工作台。主画布承载任务和结果摘要，统一检查器按需展示报告、图表、数据与代码。
2. 本机 TypeScript 后端通过 loopback HTTP API 管理会话、数据集与运行请求。前端开发服务器将 `/api` 代理至 8080；发布版将前端静态资源直接嵌入可执行文件，避免跨域和版本漂移。
3. 确定性统计引擎直接在进程内执行方法，不通过 LLM 生成数值，也不依赖外部 R、Python、SAS 或 SPSS 运行时。
4. 每次运行绑定数据集 SHA-256、算法 ID、参数、运行状态与 run_id。执行前确认卡把样本量、变量、缺失率和常见方法风险前置给用户。
5. LLM 是可选增强层，仅参与自然语言意图和解释；配置缺失或连接失败时，专业模式沿同一统计 API 继续工作。

发布链路先构建前端，再构建后端和 Node SEA 单文件可执行程序，随后执行无外部运行时 smoke test。Demo-Pack 在独立 APPDATA 目录中连续执行三轮真实冷启动、上传与 Table One 运行，验证界面资产、API 路由、数据持久化和统计引擎来自同一构建版本。
