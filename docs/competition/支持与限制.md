# Stats Code 支持与限制

## 可信承诺

Stats Code 的统计数值由本机确定性引擎产生，不由 LLM 生成。结果携带算法、参数、数据集 SHA-256、运行状态与 run_id，便于复核和审计。LLM 仅用于自然语言意图与结果解释；未配置或连接失败时，专业模式仍可直接运行统计方法。

正式 Pro 分析遵循：**研究协议审批 → 数据质量卡 → 分析方案审批 → 确定性执行 → 诊断与导出**。协议与审批时间按会话保留。

## 当前支持

- 当前 Pro 正式路径：Table One、Welch 双独立样本 t 检验、多元线性回归、二项 Logistic 回归、Cox 比例风险回归、Kaplan–Meier 估计。
- 引擎扩展能力：单因素 ANOVA、非参数检验、相关/效应量、诊断指标、标准化/秩转换与样本量设计；是否可从当前表单直接运行以软件内覆盖矩阵为准。
- 关联与诊断：相关分析、流行病学效应量、诊断试验指标。
- 回归：线性回归、Logistic 回归、Cox 比例风险模型。
- 生存与设计：Kaplan–Meier、样本量与功效分析。
- 数据处理与复现：标准化、秩转换、R/Python/SAS/SPSS 等价代码展示。
- 本机交付：单文件 Windows 可执行程序、内嵌前端、离线核心统计流程。

## 当前限制

- 尚未提供倾向评分匹配、TMLE、竞争风险、时空模型和 CDISC 全流程。
- 本产品仅提供科研设计与统计分析辅助，不独立作出诊断、治疗或个体决策；研究结论须由具备资质的研究者审核。
- 因果结论需要研究设计与识别假设支持；系统会提示因果措辞风险，但不会自动证明因果关系。
- 小样本、高缺失率、配对数据误用独立样本检验等风险会在执行前提示，最终方法选择仍由用户确认。
- `P > 0.05` 是结果而不是方法风险；系统不会因为“不显著”自动建议换模型。低功效提示只用于研究设计阶段，不提供分析后的“观察功效”判断。
- LLM 关闭时不提供自然语言解释，但不会影响统计数值、报告、图表与等价代码。

## 数据与隐私

演示数据与统计计算均保存在本机应用数据目录。使用真实敏感数据前，应遵守所在组织的数据治理、知情同意和脱敏要求。
