Stats Code 固定演示剧本（约 4 分钟）
===================================

00:00—00:25  一句话定位
“Stats Code 是面向医院科研、公卫和医学院校的本地可审计观察性研究智能体。
它先固定研究协议，再由确定性引擎本机计算；LLM 不生成统计数值。”

00:25—00:50  无 LLM 进入
在首次配置页点击“暂不配置，进入专业模式”。指出：没有 API Key 仍能完成统计分析，
只是跳过 AI 解读。

00:50—01:25  研究协议
点击“协议”，选择“加载演示协议”，快速展示研究问题、研究设计、目标人群、时间零点、
结局、estimand、缺失策略与主/敏感性分析，然后点击“审批协议”。指出：协议按会话持久化，
未审批时正式分析按钮不可用。

01:25—01:50  上传与配置
上传 data\demo_cohort.csv，选择“基线特征表”：
- 分组变量：disease
- 连续变量：age、bmi
- 分类变量：sex、smoke

01:50—02:20  数据质控与方案审批
点击运行，展示不可跳过的数据质量卡：方法、变量、样本量、缺失率和风险提示；
强调系统不会在用户批准方案前调用后端执行。随后点击“批准方案并运行”。

02:20—02:55  结果与可信度
展示对话流中的紧凑结果摘要和“本机确定性引擎 · 数值非 LLM 生成 · 可审计”。
说明同一数据和参数可得到可复核结果，运行元数据包含算法、数据哈希和 run_id。

02:55—03:30  按需检查器与验证水位
点击右上角“检查器”，依次展示报告、图表、数据和等价代码；再收起检查器，
指出 R/Python/SAS/SPSS 的 live / recorded / sidecar_only / none 覆盖等级不会混写成“均已验证”。

03:30—04:00  快照、边界与收束
点击“导出审计快照”，展示保存反馈；
打开侧边栏底部“关于与能力边界”，明确当前支持与不支持范围。
结束语：“Stats Code 只提供科研统计辅助，不作独立诊断、治疗或个体决策；
协议先行、本地执行、人审确认、可审计复现。”

演示兜底
--------
- 浏览器未自动打开：访问程序窗口显示的 127.0.0.1 地址。
- 8080 被占用：程序会自动选择 8081—8200。
- LLM 未配置或连接失败：点击“暂不配置，进入专业模式”，核心统计流程不受影响。
- 网络不可用：本演示的上传、计算和界面均在本机完成。
