Stats Code 固定演示剧本（约 3 分钟）
===================================

00:00—00:25  一句话定位
“Stats Code 是面向统计工作流的本机优先分析工作台。LLM 只负责自然语言交互和解释，
所有统计数值都由确定性引擎计算并保留可审计凭证。”

00:25—00:50  无 LLM 进入
在首次配置页点击“暂不配置，进入专业模式”。指出：没有 API Key 仍能完成统计分析，
只是跳过 AI 解读。

00:50—01:20  上传与配置
上传 data\demo_cohort.csv，选择“基线特征表”：
- 分组变量：disease
- 连续变量：age、bmi
- 分类变量：sex、smoke

01:20—01:50  执行前确认
点击运行，先不确认。讲解确认卡中的方法、变量、样本量、缺失率和风险提示；
强调系统不会在用户确认前调用后端执行。随后点击“确认并运行”。

01:50—02:25  结果与可信度
展示对话流中的紧凑结果摘要和“本机确定性引擎 · 数值非 LLM 生成 · 可审计”。
说明同一数据和参数可得到可复核结果，运行元数据包含算法、数据哈希和 run_id。

02:25—02:50  按需检查器
点击右上角“检查器”，依次展示报告、图表、数据和等价代码；再收起检查器，
说明这种布局保留 Codex 单任务工作台的专注感，同时不牺牲专业分析深度。

02:50—03:00  收束
打开侧边栏底部“关于与能力边界”，明确当前支持与不支持范围。
结束语：“可用、可信、可解释，且不把统计正确性交给模型猜测。”

演示兜底
--------
- 浏览器未自动打开：访问程序窗口显示的 127.0.0.1 地址。
- 8080 被占用：程序会自动选择 8081—8200。
- LLM 未配置或连接失败：点击“暂不配置，进入专业模式”，核心统计流程不受影响。
- 网络不可用：本演示的上传、计算和界面均在本机完成。
