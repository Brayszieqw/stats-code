## 2. E2E 层新发现

| 编号 | 严重度 | 发现 |
|---|---|---|
| D14 | 低 | 静态资产缺失时（如 /assets/*.woff2 不存在）SPA 兜底返回 index.html 而非 404，浏览器报一串 OTS 字体解析错误——调试有干扰，建议 /assets/ 前缀 miss 返回 404 |
| O3 | 观察 | 简易模式追问卡要求填"数据集 ID"（UUID 语义），对小白用户偏技术化；建议追问时直接给数据集选择器 |
| O4 | 观察 | Part4 一次未复现的 pageerror（内容未捕获到 message），建议前端给 window.onerror 加结构化上报便于定位 |
| 覆盖缺口 | — | 桌面 Electron 壳、语音录入（需真实麦克风）、移动端窄屏响应式、快照导出 UI 按钮，本轮云端未覆盖（见记录 07 未覆盖清单） |

## 3. 评委总评（UI/UX）

工作流设计是这款产品最强的部分：**五步研究门在 UI、API、引擎三层表现完全一致**，"数值非 LLM 生成、可审计"的信任叙事贯穿每个结果卡；数据质控面板、逐列类型徽标、三线表排版、四语言等价代码都到位。中文文案专业统一。改进空间集中在：主键白名单/权重启发式的误伤（D11/D12，配合 UI 无引导时用户会卡死在审计步）、简易模式追问的技术化词汇（O3）、以及 7 个引擎算法未暴露到配置器（G2，配置器只有 7 模块）。
