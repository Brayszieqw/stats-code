## 5. 快照导出 UI 按钮（U5 补上）——**发现真 bug D16**

走完整流程到第 5 步"诊断与导出",找到「审计与复现」卡片和**「下载审计快照」按钮**（附 `snapshot-<runid>-<sha>.zip` 文件名 + 说明"统计数值由本机确定性引擎生成,不是大模型推算"）。

**点击后浏览器显示红色错误**:`导出失败 EEXIST: file already exists, mkdir '/home/claude/stats-code/repo/ts-...'`（截图 97）。

API 侧独立复现,厘清导出器 destination 处理:
| destination | 结果 |
|---|---|
| 正常文件路径 `/tmp/ok.zip` | 200 ✓ |
| 同一文件路径第二次 | 200 ✓（rename 覆盖正常）|
| 指向已存在的**目录** | **500 EISDIR** |
| 父目录不存在 | **500 ENOENT** |
| （UI 触发）| **EEXIST mkdir**（第三种形态）|

→ 旗舰"审计快照"（信任三件套之一）的主下载按钮在真实点击下会报未处理的文件系统错误。详见 D16。
