# Stats Code 已知限制与防护说明

日期：2026-07-27 ｜ 适用版本：kiro/dual-mode-frontend 工作区（ts-backend 676 + web 327 = 1003 测试全绿基线）

## 设计边界（有意为之，非缺陷）

1. **LLM 不接收数值载荷、不计算数字。** 所有统计量由本地确定性引擎计算；LLM 仅做意图识别与方法学提示。LLM 输出若含数字、诊疗措辞或超长文本会被自动丢弃，回退到内置的确定性方法注记。
2. **正式分析必须通过服务端研究门**（协议审批 → 数据审计 → 分析计划批准），任何入口绕不过；只读的数据概览（inspect）豁免审批，但运行记录带 `gate: "exempt"` 审计标记。
3. **运行注册表在内存中**：后端重启后历史运行的快照导出返回 404 与中文提示（"请重新运行分析后再导出"），属预期行为而非故障。
4. **数据审计角色采用"声明-采纳制"**：用户在审计请求中声明的角色（主键、权重等）若列存在即被采纳并计入审计哈希链；主键唯一性按"采纳键 ∪ 服务端推断键"双重校验，改绑主键无法掩盖原始标识列的重复。防篡改依托哈希链绑定，而非一律拒绝用户声明。

## 能力分层（如实宣示）

- 引擎实现并通过数值验证（parity 基线 + 第三方 oracle 交叉验证）的算法共 **17 个**；
- 其中 **10 个可从界面/HTTP 实际运行**：基线特征表、t 检验、方差分析、相关分析、线性回归、Logistic 回归、Cox 回归、Kaplan-Meier，以及经合并 `power` 技能可达的 phase3 / 单臂功效设计；
- 其余 **7 个（非参数检验、OR/RR、归因危险度、标准化、寿命表、ROC、power_phase2）目前仅引擎级验证**，暂无运行入口；
- `/api/coverage-matrix` 对每个算法以 `ui_runnable` 字段逐条标注，界面能力与引擎能力不混淆。

## 已知限制（当前版本）

1. 前端打包体积偏大：index ≈1.5 MB、antd ≈1.0 MB（构建时有 >600 kB 警告），另有一个 1 字节的空 react chunk（manualChunks 配置遗留）。只影响首屏加载速度，不影响功能与正确性。
2. 快照下载会在后端工作目录 `exports/` 留存 zip（按 runId 命名，同一 run 重复导出覆盖），暂无自动清理。
3. 未配置 LLM 时的离线关键词路由中，"组间对比"一词固定路由到 t 检验；三组及以上数据会得到明确报错，需改说"方差分析"。
4. 列类型自动推断偏保守：低基数整数列（≤6 个不同取值、≥20 非缺失行、存在重复）判为分类变量，其余整数列与含小数列判连续；判错时可在专业模式配置器手动调整。
5. 仅支持 CSV/TSV 文本表格且 ≤70 MiB；编码自动探测覆盖 UTF-8（含 BOM）、GBK、UTF-16 LE/BE（含无 BOM 启发式），其余编码按 GBK 回退解码。
6. CORS 已收紧为仅回显 loopback 来源、跨源写操作直接 403，但**未做 Host 头校验**：极端 DNS-rebinding 场景下同源读取仍属理论攻击面（本产品绑定 127.0.0.1，实际暴露有限）。
7. t 检验分组按数据首现顺序，差值符号可能与 R/SPSS（按水平排序）相反；|t|、p、df 完全一致，结果 payload 中明示了组顺序。
8. 简易模式的追问卡要求填写"数据集 ID"（UUID），对新手偏技术化；专业模式不受影响。
9. 桌面（Electron）壳与语音录入（需麦克风权限）未纳入本轮真机回归。
10. 低配或高负载机器上跑全量测试时，快照类用例的 PowerShell 解压首次冷启动可达 24–28 秒；测试超时已设 60 秒兜底。

## 防护措施摘要（已验证）

- 全部 API 入口有输入校验与结构化中文错误：畸形 JSON→400、缺 text 字段→422、超长消息（>8000 字符）→413、非法 base64 数据集→422、退化/非法分析输入（单组 t 检验、完全共线、零方差、非数值文本、未知相关方法等）→422 且保留清晰错误消息、非法 runId→400、未批准运行→428/403、会话不存在→404；500 仅保留给真正的内部异常。
- CORS 仅回显 `127.0.0.1`/`localhost`/`[::1]` 来源（带 `Vary: Origin`），陌生来源的预检与写操作一律 403 `ForbiddenOrigin`（curl 真机验证：跨源 GET 无 ACAO 头、跨源 POST 无副作用）。
- Spawn 哨兵对 R/SAS/Python/SPSS 等外部统计运行时的阻断在所有平台一致（`.exe/.bat/.cmd/.com` 后缀剥离平台无关）。
- 快照导出对空路径/目录路径/不存在的父目录做归一化与友好报错（400/409/413 结构化错误码），同一路径重复导出稳定成功；`replay <zip> [--sha256]` 完整性门控不受影响。
- CLI 对未知 flag 显式报错退出（exit 2）而不再静默启动服务；`/assets/*` 未命中返回 404 而非 SPA 兜底。
- p 值尾部数值精度：normalCdf 以不完全伽马函数计算，极端 Wald 检验（|z| 达 30）p 值保持 1e-6 级相对精度、不塌缩为 0。
- SSE 流中途失败发送结构化 error 帧并正常终止（`done` 帧仍到达），响应头含 `charset=utf-8`，非浏览器客户端中文不乱码。
- 连续多轮对话（含审批门拒绝、真实 LLM 调用）后会话状态一致，删除会话后干净返回 404。
- 打包脚本内置密钥扫描与禁运文件名单（llm-config.json/.env 等），安装脚本拒绝携带密钥文件；API Key 仅存于本机 `%APPDATA%\stats-code\`，不进安装包。
- 构建守卫以内容指纹 + 产物清单校验判断 dist 新旧，防止陈旧构建被误用。
