# 单命令启动器

> 横切概念：用户敲一条 `stats-code`（不带子命令）就完成「启动后端 + 伺服前端 + 开浏览器 + 前台运行」。

## 行为

1. 启动后端 HTTP（从 `8080` 扫描首个可 bind 端口）
2. prod：同端口伺服内嵌前端静态资源；dev：Vite `:5173` 代理 `/api`
3. 自动用系统默认浏览器打开实际地址
4. 前台运行，Ctrl+C 停止

旗标：`--version` · `--help` · `--no-browser`。**没有公开算法子命令。**

## 实现位置（TS）

| 层 | 模块 |
|----|------|
| 入口 | [[TS-api]] `launcher.ts` / `bin.ts` |
| 原语 | [[TS-engine]] `launcher/`（端口、浏览器、锁） |
| 发布 | Node SEA 单文件 exe + `install.ps1` |

## 关键细节

- **单实例**：lock 文件记录 PID + URL；已有实例则打开既有 URL 后退出
- **prod**：`scripts/release.ps1` → web build → ts-backend build → SEA → smoke
- **dev**：仓库根 `启动Stats前端.bat`（先 build dist 再起 dev-server + Vite）

## 分发

单文件 `stats-code.exe`（内嵌 Node 运行时 + 前端 dist），见 [[ADR-0001-单文件exe分发]]。
