# 单命令启动器

> 横切概念:用户敲一条 `stats-code`(不带子命令)就完成"启动后端 + 启动前端 + 开浏览器 + 前台运行"的全部逻辑。

## 行为

1. 启动后端 axum 服务(从 `8080` 扫描,首个可 bind 的端口)
2. 启动前端(dev:vite `:5173`;prod:后端直接吐内嵌静态资源)
3. 自动用系统默认浏览器打开前端地址
4. 前台运行,Ctrl+C 停止全部

唯一旗标:`--version` `--help`。**没有公开子命令。**

## 实现位置

| 层 | 模块 |
|----|------|
| Rust | [[Rust-stats-code]] `launcher/`(端口扫描、浏览器、进程守卫 process_guard) |
| TS | [[TS-engine]] `launcher/` + [[TS-api]] `launcher.ts` |

## 关键细节

- **单实例**:`%APPDATA%\stats-code\running.lock` 写 PID+URL;已有实例则直接开浏览器后退出。
- **进程守卫**(Windows):用 Win32 Job Object FFI 确保 Rust 主进程退出时杀掉 vite 子进程(这是 workspace 里唯一允许 `unsafe` 的地方,见 `Cargo.toml` lints 注释)。
- **prod/dev 切换**:Cargo feature `dev-vite`(Rust)。
