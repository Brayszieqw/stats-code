# 审计快照

> 横切概念：把一次分析运行导出为可复现、可审计的快照。记录数据、算法、版本、环境，使结果可被第三方核验。

## 快照内容

| 文件 | 内容 |
|------|------|
| `manifest.json` | schema v2；运行元数据与除自身外全部成员的 SHA-256 清单 |
| `versions.json` | `commit_sha`、运行时依赖版本 |
| `workflow.yaml` | 分析工作流定义 |
| 数据 / 结果 | 经脱敏的输入与输出 |

## 实现位置（TS）

- Engine：[[TS-engine]] `snapshot/` + `version.ts`
- 前端：[[Web-前端]] `ExportSnapshotButton.tsx` + `useSnapshotExport.ts`
- 路由：`POST /api/snapshot/export`（[[TS-server]]）

## 可信度基础

脱敏（`redact`，密钥/路径）+ Spawn Policy 哨兵（证明未调用外部统计软件）。见 [[Parity与Sidecar]] 与 [[ADR-0003-TS后端进程内算法]]。

## 回放验证

导出响应会返回整包 SHA-256，服务端运行注册表也保留最近一次成功导出的锚。第三方可直接验证 zip，无需手工解包：

```powershell
stats-code replay .\audit-snapshot.zip --sha256 <导出返回的 sha256>
```

该命令只接受未加密的 Stored ZIP，解包前校验成员路径、重名、CRC、大小与边界；随后核对 manifest v2 的精确成员集合、全部成员摘要、workflow 输入输出摘要和版本契约。回放分支不启动 HTTP server、不打开浏览器，也不创建单实例锁。未提供 `--sha256` 时仍校验全部成员，但会明确警告 manifest 缺少外部信任锚。
