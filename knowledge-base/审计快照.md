# 审计快照

> 横切概念:把一次分析运行导出为可复现、可审计的快照。记录数据、算法、版本、环境,使结果可被第三方核验。

## 快照内容

| 文件 | 内容 |
|------|------|
| `manifest.json` | 含 `stats_code_release_version` 等清单 |
| `versions.json` | `commit_sha`、`runtime_dependencies`(直接依赖版本) |
| `workflow.yaml` | 分析工作流定义 |
| 数据 / 结果 | 经脱敏的输入与输出 |

## 实现位置
- Rust:[[Rust-stats-code]] `snapshot/`(版本号由 `build.rs` 编译期注入 `RELEASE_VERSION` / `COMMIT_SHA` / `RUNTIME_DEPS_JSON`)
- TS:[[TS-engine]] `snapshot/` + `version.ts`
- 前端:[[Web-前端]] `ExportSnapshotButton.tsx` + `useSnapshotExport.ts`
- 后端路由:`POST /api/snapshot/export`(见 [[Rust-agent-server]])

## 可信度基础
脱敏(`redact`,密钥/路径)+ Spawn Policy 哨兵(证明没偷调外部统计软件)。见 [[Parity与Sidecar]] 和 [[ADR-0003-TS后端进程内算法]]。
