# 统计引擎

> 横切概念:Stats Code 的所有统计算法集合。纯实现(Rust 自带 Newton-Raphson 等),零外部运行时依赖,已通过 Python/R 数值一致性验证。

## 两处实现
- Rust:[[Rust-stats-code]] 的各 `.rs` + `stats/` 模块(子进程调用)
- TS:[[TS-engine]] 的 `stats/` + `math/`(进程内纯函数,见 [[ADR-0003-TS后端进程内算法]])

## 已实现算法(主体)

### 回归 / 建模
- Logistic 回归(Newton-Raphson IRLS)
- Cox 比例风险(Efron/Breslow partial likelihood)
- 线性回归(OLS / QR)
- Poisson、有序/多项 Logit、混合效应模型(LMM)

### 生存分析
- Kaplan-Meier 曲线、Log-rank 检验
- 生命表(life table)、竞争风险(competing risks)

### 描述 / 检验
- TableOne(Table 1 基线表)
- t 检验(配对/单样本)、ANOVA(单因素/随机区组/重复测量)+ 事后检验
- 卡方、Fisher、McNemar、Wilcoxon、Mann-Whitney、Cochran-Armitage
- 相关、正态性、方差齐性

### 流行病学专项
- OR/RR、Mantel-Haenszel 分层
- 标准化(率)、归因风险、剂量反应
- 倾向评分匹配(PSM)+ SMD
- 诊断试验(ROC/AUC、Bland-Altman、Kappa)
- 功效/样本量(Power,见 [[ADR-0005-Power家族对齐SAS]])
- Meta 分析、PCA、LDA、聚类
