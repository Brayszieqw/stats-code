# 统计引擎

> 横切概念：Stats Code 的统计算法集合。实现于 [[TS-engine]]（`packages/engine`），**进程内纯函数**，零外部统计运行时依赖（不 spawn R/SAS/Python/SPSS）。

## 实现位置

- **唯一实现**：[[TS-engine]] 的 `stats/` + `math/`（见 [[ADR-0003-TS后端进程内算法]]）
- 调用方：[[TS-server]] skill runner 直接 import，不经子进程

## 当前算法（`AlgorithmId`，17 项）

与 `packages/engine/src/stats/index.ts` 对齐：

| 族 | ID |
|----|-----|
| 描述 | `tableone` |
| 检验 | `ttest` · `anova` · `nonparametric` · `correlation` |
| 流行病学 | `standardization` · `or_rr` · `attributable_risk` |
| 生存 | `kaplan_meier` · `cox` · `life_table` |
| 回归 | `linear` · `logistic` |
| 功效 | `power_single_arm` · `power_phase2` · `power_phase3` |
| 诊断 | `diagnostic_roc` |

> 文档禁止宣称「已实现」而未出现在上表中的方法（如 Poisson、混合效应、竞争风险、PSM、Meta 等——那些是 **规划项**，见 [[发展路线图]]）。
