# 领域语言

> 共享词汇表(源自 `CONTEXT.md`)。理解代码和对齐沟通时按这里的定义。

## 产品命令
- **`stats-code`(命令)**:全局可执行二进制。不带子命令时执行 [[单命令启动器]] 的全部行为。唯一旗标 `--version` `--help`。
- **内部算法子命令**:`tableone`/`survival`/`ttest`/`power`/`workflow`/`init`/`doctor` 等。**不是公开用法**,仅供 [[Rust-agent-core]] 通过 `SkillInvoker::StatsCli` 子进程调用(Rust 版;TS 版见 [[ADR-0003-TS后端进程内算法]])。

## 部署形态
**本地单机模式**(类似 Jupyter Lab):用户在自己电脑跑 `stats-code.exe`,后端绑 `127.0.0.1:8080` 不对外,数据落本地。多用户/认证/集群**不在当前范围**。

## 角色
- **前端** = [[Web-前端]](`web/`)
- **后端** = [[Rust-agent-server]](`crates/agent-server`)/ [[TS-server]]
- **算法引擎** = [[统计引擎]]([[Rust-stats-code]] 内部 / [[TS-engine]])
- **Agent Core** = [[Rust-agent-core]](TS 版无对应包,见 [[ADR-0004-TS三层包结构]])

## 运行模式
- **prod**:`cargo build --release`,前端编译期嵌入二进制,单进程 axum `:8080` 同时服务 API + 静态资源,用户机**不需要 Node**。
- **dev-vite**:Rust 主进程 spawn vite 子进程,axum `:8080` + vite `:5173`。

## LLM 配置
见 [[LLM集成]]。Key 存明文 TOML `%APPDATA%\stats-code\config.toml`。

## 历史用法(已废弃)
- `start.ps1` 双窗口启动 → 已删除,由 `stats-code` 单命令取代
- `stats-code chat` 终端 REPL → 已删除(v0.x)
- 公开的 `init/doctor/workflow run` → 用户不再直接敲,代码保留供内部调用
