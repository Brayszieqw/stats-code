# 领域语言

> 共享词汇表（源自 `CONTEXT.md`）。理解代码和对齐沟通时按这里的定义。权威细节以 `CONTEXT.md` 为准。

## 产品命令

- **`stats-code`（命令）**：全局可执行二进制。不带子命令时执行 [[单命令启动器]] 的全部行为。旗标：`--version` · `--help` · `--no-browser`。
- **内部算法入口**：`tableone` / `survival` / `ttest` / `power` 等——**不是公开 CLI**。由 [[TS-server]] 通过 skill 直接调用 [[TS-engine]] 进程内纯函数（见 [[ADR-0003-TS后端进程内算法]]）。

## 部署形态

**本地单机模式**（类似 Jupyter Lab）：用户本机跑 `stats-code.exe`，后端绑 `127.0.0.1:8080`，数据落本地用户目录。多用户 / 认证 / 集群**不在当前范围**。

## 运行模式

- **prod**：Node SEA 单文件 exe，同端口 API + 内嵌静态资源；用户机**不需要** Node/R/SAS/Python。
- **dev**：`启动Stats前端.bat` → build dist → `dev-server.mjs`（:8080）+ Vite（:5173）。

## LLM 配置
